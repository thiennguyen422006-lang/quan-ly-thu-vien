
# Quan Ly Thu Vien - Java

## Gioi thieu
Chuong trinh quan ly tai lieu thu vien bang Java.

## Chuc nang
1. Them sach, tap chi, bao.
2. Xoa tai lieu theo ma.
3. Hien thi danh sach tai lieu.
4. Tim kiem theo loai tai lieu.
5. Thoat chuong trinh.

## Kien thuc Java
- Class va Object
- Ke thua (extends)
- Da hinh (override)
- Dong goi (private, getter, setter)
- ArrayList
- Switch-case va vong lap

## Cau truc
- Main.java: ma nguon chuong trinh.
- catalog.csv: danh muc tai lieu mau da ghi nguon.

## Cach chay
Mo Main.java trong VS Code va chay ham main.

## Luu y
Phien ban hien tai luu du lieu trong bo nho.
Du lieu nhap khi chay khong tu dong duoc luu vao catalog.csv.
